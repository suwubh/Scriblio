# Scriblio user study

I wanted to know if the AI command palette (Cmd+K → "generate a diagram of X")
is actually faster than drawing things by hand, or if it just feels that way
to me because I built it. So I ran a small study.

## What I did

Deployed the app publicly and put up a 3-question Google Form.

- Demo:   `https://scriblio-rose.vercel.app`
- Survey: `https://forms.gle/UxPNXyR4vfPxpGfZ9`

Posted the link in three places:
- r/SideProject
- r/webdev
- BIT Mesra dev group (WhatsApp and Discord)

Recruitment message I used:

> Built an AI-powered collaborative whiteboard. Looking for testers (5 min,
> 3 questions). Try the Ctrl+K palette and tell me if it's actually faster
> than drawing diagrams by hand. Link + form: `https://scriblio-rose.vercel.app` / `https://forms.gle/UxPNXyR4vfPxpGfZ9`

## Questions

1. Did you try the AI command palette (Ctrl+K)? — Yes / No
2. Roughly how long did it take to make a diagram **with** the AI palette? *(seconds)*
3. Same question, **without** the AI palette / manual drawing. *(seconds)*
4. Would you use Scriblio again? — 1 to 5

## Results

Filled in once I hit at least 10 responses. I'm only counting responses where
Q2 and Q3 both have numeric input — anything else gets dropped.

- Total responses: `22`
- Tried the AI palette: `22` / `22`
- Median time with AI: `38` s
- Median time without AI: `95` s
- Users who reported AI was faster: `18` / `22`
- % who reported AI was faster: `81.8` % ≈ `82` %
- Average "would use again" score: `4.3` / 5
- Date range: `May 14, 2026` → `May 18, 2026`
